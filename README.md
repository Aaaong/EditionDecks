# Edition Decks

A standalone Balatro mod (Steamodded) that adds one deck per edition.
All cards in the run have the deck's edition, and cards cannot change editions. Each deck unlocks after discovering every edition.

## Credits

This mod is derived from the **Edition Deck** in [Cryptid](https://github.com/SpectralPack/Cryptid) by **MathIsFun_**.
The deck concept, the edition-locking and forced-edition logic, and the Lovely patches originate there.
The sprites are created with generative AI.
